# MakeEmoji offline backup

Archive of the verified MakeEmoji.com discovery used by DN Cards `/emoji`.

## Purpose

MakeEmoji.com is the **primary** generator today. This package preserves everything
we discovered so we can eventually run a fully independent offline engine if the
site changes, goes offline, or becomes inaccessible.

```text
MakeEmoji available  →  makeemoji-browser (primary)
MakeEmoji unavailable →  offline provider (ONLY if EMOJI_ALLOW_OFFLINE_FALLBACK=1)
```

Offline fallback is **disabled by default**.

## Contents

| Path | What |
| --- | --- |
| `VERSION` | Backup package version |
| `manifest.json` | Offline package metadata (`offlineReady`, style counts) |
| `styles.json` | Full discovered style registry (473 styles) |
| `controls.json` | Discovered listbox/control values (speed, size, …) |
| `makeemoji-source-manifest.json` | Snapshot of the live discovery manifest |
| `renderer/mappings.json` | Exact-name styles currently implementable offline |
| `metadata/` | Source-site provenance |
| `checksums.json` | SHA-256 hashes (regenerated by the backup script) |
| `makeemoji-offline-backup.zip` | Reproducible archive of this package |

## Regenerating the ZIP

```bash
pnpm makeemoji:backup
```

That rebuilds `styles.json` from the live MakeEmoji provider manifest (if present),
rewrites checksums, and recreates the ZIP.

## Offline-capable styles (partial)

Only styles whose **exact discovered name** overlaps a local procedural effect
are marked `offlineImplemented: true` today (see `renderer/mappings.json`).
All other styles are archived as metadata for future reimplementation — we do
**not** pretend they render offline yet.

`offlineReady` stays `false` until a full independent generator exists.
