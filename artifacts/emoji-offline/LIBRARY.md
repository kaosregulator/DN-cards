# MakeEmoji offline library

**473 / 473 styles offline-ready** (default generator).

Source of truth: https://makeemoji.com/

## Colour side-control (animate the image itself)

On MakeEmoji this is the **Colour** dropdown beside Speed/Direction — it is **not** a style tile.
It recolors the upload *before* a style runs.

| Mode | Values | Behavior |
| --- | --- | --- |
| Animated | Colors, Rainbow, Stripes, Circles | Looping GIF even with style `none` |
| Static looks | Deep Fried, X-Ray, Toxic, Vaporwave, Cherry Cola, Night Vision, Blue Flame, Newsprint, Hellfire | Single-pass filter |
| Tints | Red, Orange, Yellow, Green, Blue, Purple | Solid hue tint |

### How to use in Discord `/emoji`
1. Upload / pick an image
2. Set style to **none** (first in the browser) for Colour-only, *or* any style to stack
3. Open **Colour** and pick Colors / Rainbow / Stripes / Circles (or a static look)
4. Generate — Speed still controls playback rate
