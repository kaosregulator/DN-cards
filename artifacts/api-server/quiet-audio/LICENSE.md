# Quiet Audio — licenses

All **shipped** Quiet Room ambience in this bot is generated at runtime / cache-time
with **ffmpeg** (noise, filters, simple tones). These recordings are **original
works generated by the bot** and are treated as public-domain / freely redistributable
for this project.

Spoken quotes (when enabled) are synthesized with **ffmpeg flite** (CMU Flite),
which is a free software speech synthesizer. Quote *text* is original project content.

## Future external samples

If you add downloaded samples under `quiet-audio/` or the cache:

| Field | Required |
|-------|----------|
| source URL | yes |
| license (CC0 / CC-BY / …) | yes |
| attribution text | if license requires |
| date fetched | recommended |

Never commit copyrighted commercial music.
