# Kaos HQ — UI reference mockups

Design mockups uploaded by the project owner as the **visual source of truth** for
the unified HQ redesign. Discord renders embeds + canvas, so treat these as the
look, layout, and feature intent to match closely — not a literal web UI.

| File | Screen | Key elements |
|---|---|---|
| `01-…scene_a.png` | **Base Overview** | Isometric base, castle, river, fences, trees. Buildings: Mounted Turret, Defender, Gold Mine. Right rail: Base Upgrade (Health / Defense / Storage / Income), Buy Shield. Quick Actions. No edit grid. Shield = subtle blue aura. |
| `02-…editor_scene.png` | **Base editor — Edit Mode** | Category tools (Terrain / Water / Structures / Decorations / Fences / Clear). Skyboxes (Clouds, Night, Winter…). Floor tiles. Palette tabs. Quick Layers. Undo/Redo. Grid ON while editing. |
| `03-…isometric_st.png` | **Base editor — Move Mode** | Selected item + directional move, Place / Cancel. Live placement preview. |
| `04-…room_editor.png` | **Room interior editor** | Same editing engine indoors. Categories: Walls / Doors / Floors / Decor / Furniture / Lighting / Trophies / Defense. Room themes strip with bonuses. |
| `05-…dashboard.png` | **Room editor (alt)** | Room Blueprints strip, fuller wall set, Move Mode placing wall segments. |

## Currency note

Mockups show a gem-style currency. Live game uses **shards** 💠 via the existing
economy — keep shard costs; do not invent a second currency.
