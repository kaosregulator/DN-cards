# DN Cards - Operations Center Add-on

IMPORTANT

This is an ADD-ON to the existing DN Cards project.

DO NOT replace, refactor, or break any existing systems including:
- Help System
- Echo Secret
- Cards
- Battles
- Economy
- Admin Panel
- Existing Settings
- Existing Permission Framework

Integrate using the current architecture and coding style.

---

## Goal

Create a new Operations Center module.

This is a professional live operations system for Discord communities.

It should work for any Discord server while shipping with sensible defaults.

This is NOT Military Tycoon specific.

Military Tycoon support is simply one use case.

---

## Core Philosophy

One operation type = One permanent embed.

Never spam new embeds.

Never flood channels.

Every operation updates its existing board.

Examples

• Staff Request
• Combat Support
• Base Defense
• Convoy Escort
• Event Support

Each board lives forever.

---

## Default Operations

Provide built-in operations.

staff_request

## Queue

If an operation already exists:

Do NOT create another embed.

Queue it.

When completed:

Automatically promote the next queued request.
