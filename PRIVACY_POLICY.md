# Privacy Policy

**DN Cards Discord Bot**

*Last Updated: July 2026*

## 1. Information We Collect

The Bot collects and stores the following data necessary for gameplay:

- **Discord User IDs** — for account identification and game progression
- **Discord Usernames** — for display in leaderboards and trade history
- **Guild IDs** — for server-specific game state and configuration
- **Game Data** — card collections, inventory, currency balances, achievements, trade history
- **Interaction Data** — timestamps of commands used and game events

## 2. How We Use Data

We use collected data to:
- Provide and maintain the Bot's functionality
- Store and retrieve user game progress
- Display leaderboards and rankings
- Process trades and transactions
- Generate usage analytics for service improvement
- Comply with Discord's API requirements

## 3. Data Storage

- All data is stored in a PostgreSQL database
- Data is encrypted in transit and at rest
- Only authorized personnel have access to the database
- Backups are maintained for service continuity

## 4. Data Retention

- Game data is retained as long as the user's account is active
- Data may be retained for up to 30 days after account deletion for backup purposes
- Deletion requests can be made through server administrators

## 5. Third-Party Services

The Bot uses:
- **Discord API** — for bot functionality and user authentication
- **Google Cloud Storage** — for image and media storage (if enabled)
- **PostgreSQL Database** — for data persistence

We do not sell, trade, or share user data with third parties for marketing purposes.

## 6. User Rights

You have the right to:
- Request information about what data we hold
- Request correction of inaccurate data
- Request deletion of your data (subject to legal retention requirements)

## 7. Security

We implement industry-standard security measures to protect user data. However, no system is completely secure. We cannot guarantee absolute security of data in transit over the internet.

## 8. Children's Privacy

The Bot is not intended for use by children under 13. We do not knowingly collect data from children under 13. If we become aware of such collection, we will take steps to delete the information.

## 9. Changes to Privacy Policy

We reserve the right to update this Privacy Policy. Changes will be effective immediately upon posting. Your continued use of the Bot constitutes acceptance of updates.

## 10. Contact

For privacy-related inquiries or data requests, please contact:
- Server Administrator
- DarkNight community leads
